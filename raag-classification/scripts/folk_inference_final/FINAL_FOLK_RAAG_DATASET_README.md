# FINAL FOLK RAAG DATASET README

## Dataset Purpose
This dataset contains the **computational model-generated Raag hypotheses** for the 328 Indian Traditional Folk recordings analyzed during the research internship. The primary purpose of this dataset is to provide structured, mathematically derived hypotheses about the structural and melodic affinities of these recordings, rather than definitive, human-verified musicological labels.

## Machine Learning Model
The predictions in this dataset were generated by the computationally frozen **45.02% Hybrid SVM B** model.
- **Training Data:** 635 pure classical recordings from the TRF TRAIN dataset.
- **Test Performance:** 45.02% Top-1 accuracy on the sealed classical TRF Test set.
- **SARAGA Generalization:** 56.60% Estimated-Tonic Top-1 accuracy on the independent SARAGA classical dataset.
- **Architecture:** 1884-dimensional extraction (Transition Matrices, Pitch-Class, N3 Trigrams). 75% Geometric retrieval (Cosine Similarity) fused with 25% Discriminative classification (RBF-SVM).

## Folk Inference Status
- **Attempted Recordings:** 328
- **Successfully Processed:** 327
- **Failed Recordings:** 1 (Audio was un-voicable or too short for continuous 60s pitch-tracking extraction).
- *Failed recordings are isolated in the `FOLK_INFERENCE_FAILED_RECORDINGS.csv` file.*

## Metadata Recovery and Song Titles
To enhance the human readability of the dataset, explicit song titles and artist names have been recovered using authoritative metadata:
- **Baul Recordings:** 30 Baul recordings have been mapped directly to their actual song titles using `Baul_metadata.xlsx`.
- **`recording_id`:** This remains the immutable computational identifier connecting the predictions to the raw audio file.
- **`song_name`:** Original song title where authoritative metadata exists. Titles were strictly verified and were NOT manually guessed or fabricated.
*Note: The addition of explicit song names does NOT constitute modifying, validating, or evaluating the computational Raag hypotheses. The machine-learning predictions remain fully frozen and untouched.*

## Important Scientific Limitation
There is currently no independent ground-truth annotation for this Folk corpus.
Therefore, the field `predicted_raag_top1` must **NOT** be treated as a confirmed Raag identity. It strictly means: *"The classical Raag with the strongest structural acoustic similarity according to the frozen classical-trained model."*

## Confidence Calibration
Folk music generally exhibits Out-Of-Distribution (OOD) phrasing relative to classical grammar. The model's uncertainty is calibrated into explicit tiers based on the `hybrid_score_margin`:
- **HIGH (Margin > 0.12):** The model is mathematically highly confident in the similarity.
- **MODERATE (0.05 < Margin <= 0.12):** Meaningful structural overlap exists, but competing hypotheses are strong.
- **AMBIGUOUS (Margin <= 0.05):** The model cannot confidently distinguish between competing classical templates, signifying severe structural ambiguity or mixed-scale OOD presence.

## Future Validation
This dataset serves as the foundation for the next phase of research. A qualified human musicologist should utilize the `FOLK_RAAG_MUSICOLOGIST_REVIEW.csv` file, prioritizing the highest-confidence predictions, to blindly evaluate and document the true structural relationship between the Folk recordings and the model's hypotheses.
