EVALUATION & SUITABILITY
========================
R. Suitable for supervised classification? YES. It appears to have a reasonable minimum recordings per class.
S. Suitable for CultureMERT embedding analysis? YES. High-quality audio files can be run through the model for continuous representations.
T. Suitable for nearest-neighbor Raag matching? YES, as a robust reference database assuming the classical recordings are high quality and clean.
U. Suitable for evaluating a model? DEPENDS on independence. If all recordings in a Raag are from the same artist/concert, testing is invalid.

V. Biggest Risks:
- Data Leakage: Without explicit artist/album metadata in filenames, splitting multiple recordings from the same Raag might accidentally put the same concert in Train and Test.
- Label Noise: Potential aliases and varying transcriptions of Raag names might artificially split classes.

W. Recommended Next Step:
Use CultureMERT to extract reference embeddings for the overlapping Raags in this dataset. Then compare Folk Music embeddings against this reference bank using k-NN or Cosine Similarity to assign candidate labels.
