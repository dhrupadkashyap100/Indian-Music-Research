# RAAG CLASSIFIER COMPLETE PROJECT REPORT

## 1. Project Objective
To assign probable Raag origins to Indian folk songs using deep learning representations.

## 2. Methodology & Evidence
We verified the implementation of a pipeline that extracts CultureMERT embeddings from 5s windows, pools them into 60s L2-normalized vectors, and performs KNN against a TRF reference dataset.

## 3. Verified Novelty
Application of multi-culturally adapted foundation models (CultureMERT) to zero-shot geometric ranking of unlabelled Folk music.
